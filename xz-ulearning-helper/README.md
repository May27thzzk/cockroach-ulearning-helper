# 莞工小蟑螂 - 优学院全能助手

当前发布版本：**v4.4.11**。

本目录提供可安装脚本、版本索引、完整更新日志、当前版本验收报告和发布截图。

## 安装

在 Tampermonkey 中打开 `莞工小蟑螂-优学院全能助手.user.js` 并确认安装；也可以新建用户脚本后粘贴文件内容。登录优学院后进入课程学习页，点击右侧小蟑螂按钮打开面板。

## 功能

- 课程目录预读、全课进度、当前页标题和手动定位。
- 自动播放、读书计时、翻页确认与长时间运行日志。
- 题库导出、练习分组识别；无法安全确认的页面会暂停。
- 浅色/暗色模式、窄屏布局、可调大小面板与安卓风格小彩蛋。
