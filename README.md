优学院课件与训练题库导出、课程进度查看、视频控制、练习处理和读书计时助手。支持东莞理工学院与标准优学院。

## 主要功能

- 按章节导出课件题库和训练题库为 JSON。
- 预读课程目录并显示整课学习进度和当前页标题。
- 提供视频播放控制、练习填写与提交、翻页确认和手动定位。
- 识别页面中的多组练习；填空和简答控件无法确认时会停留提示。
- 提供读书计时、浅色/暗色界面、可拖动面板和运行日志。

## 安装与使用

1. 安装 Tampermonkey 等用户脚本管理器。
2. 打开上方 Greasy Fork 页面，安装脚本。
3. 登录优学院并打开课程学习页、课程目录或训练题页面。
4. 点击页面上的小蟑螂按钮打开面板，选择所需功能后手动开始。
