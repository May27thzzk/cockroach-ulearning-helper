# 莞工小蟑螂 - 优学院全能助手 (xz-ulearning-helper)

从优学院导出课件题库和训练题库，支持自动刷课，兼容标准优学院和东莞理工学院版本。

当前发布版本：**v4.4.11**。安装文件、历史版本索引和逐版更新记录见[版本索引](版本索引.md)与[更新日志](CHANGELOG.md)。

## 工作原理

### API 接口分析

优学院的课件学习系统基于前后端分离架构，前端通过 REST API 与后端通信。本工具通过分析浏览器网络请求，找到了关键的数据接口：

```
GET /uaapi/course/stu/{courseId}/directory?classId={classId}
```
获取课程目录，返回所有章节和小节结构。

```
GET /uaapi/wholepage/chapter/stu/{nodeId}
```
获取章节详情，返回所有页面和题目数据。

```
GET /uaapi/questionAnswer/{questionId}?parentId={pageId}
```
获取单题答案，返回标准答案和解析。

### 平台差异

| 平台 | API 地址 | 前端地址 |
|------|----------|----------|
| 东莞理工学院 | `urlStyle=2` 时走 `ua.dgut.edu.cn/uaapi` 同源代理，否则走 `api.dgut.edu.cn` | ua.dgut.edu.cn |
| 标准优学院 | api.ulearning.cn | ua.ulearning.cn |

脚本按学习页配置选择请求地址；莞工的两种部署模式需要分别适配。

### 认证机制

请求需要携带 `AUTHORIZATION` 请求头，值为登录后获取的 Token。Token 存储在：

- Cookie: `AUTHORIZATION` 或 `token`
- 请求头: `authorization` / `ua-authorization`

Token 有时效性，过期后需重新登录，脚本会自动检测并提示。

### 数据处理流程

```
浏览器获取认证 → 调用目录API获取章节 → 逐章获取页面数据 → 4路并发获取答案 → 生成JSON下载
      ↓                    ↓                    ↓                ↓
  AUTHORIZATION         chapters[].items[]    pages[].coursepageDTOList[]    questions[]
```

## 功能特点

### 题库导出

- **课件题库导出** — 按章节选择性导出，4 路并发获取答案
- **训练题库导出** — 一键导出训练页面题目和标准答案
- **导出格式** — JSON，兼容佛脚、Anki 等刷题工具导入
- **导出进度** — 实时进度条，支持随时取消
- **导出历史** — 记录最近 10 次导出，区分课件/训练来源
- **失败自动重试** — 获取答案失败自动重试一次

### 自动刷课

- **自动播放视频** — 支持自定义倍速（1x~15x），自动静音
- **自动答题** — 支持选择题、判断题、填空题、问答题自动填写，正确率可配置
- **自动翻页** — 可设置页面停留时间，提交后自动翻页
- **答题间隔随机化** — 防止被平台检测为脚本操作
- **运行统计** — 实时显示运行时长、页数、题数、正确率
- **防挂机检测** — 每 30 秒模拟鼠标移动
- **视频卡住回退** — 检测播放进度停滞时自动回退 3 秒重试
- **读书计时** — 按设置的时长停留并尝试翻页，学习记录与学分以平台实际结果为准
- **读书计时与翻页确认** — 按实际时间计算停留时间，确认页面变化后才累计页数；连续失败会暂停并提示

### 页面定位、弹窗与双练习处理（v4.4.7 并行版）

- **手动定位** — 自动刷课暂停时，可在高级设置点击“前往首个未标记完成页”；跳过平台标记上锁的页签，并确认实际跳转结果
- **完成标记** — 按平台页签的完成状态判断；未标记完成不代表该页题目未答。没有完成标记时给出提示，不猜测目标页
- **离页提示** — 未完成题离页弹窗按“留在本页”文案识别；不认识的弹窗会暂停，避免误提交或丢弃当前题目
- **复用题目 ID 的双练习** — 同时显示时复用同一份答案填写所有题目实例；第一组提交后才出现的新组会重新识别并答题，再分别提交完整组别
- **独立分支** — 此版本位于 `cockroach-ulearning-helper-parallel`，不包含签到功能；原工作目录保持独立

### 界面设计

- **直接进入功能** — 学习页打开后直接显示自动刷课；顶部胶囊可一键切换题库导出和读书计时；目录或训练页直接显示导出
- **轻量胶囊界面** — 浅紫渐变工作区和暖白操作区分隔任务，导航、常用开关与主要操作采用胶囊形态；悬停、按下与键盘焦点均有轻量反馈，刷课与计时的开始按钮固定在面板底部
- **暗色与窄屏适配** — 支持键盘焦点提示和系统的减少动态效果设置
- **面板可拖动** — 自由移动位置，刷新后自动记忆
- **运行日志** — 可暂停滚动、清空或复制最近 500 条可见记录
- **定位反馈** — 进度状态、定时运行统计与翻页确认日志显示当前页签名称，方便长时间运行时定位卡住的位置

## 使用方法

### 导出课件题库

1. 打开优学院课件学习页面（ua.dgut.edu.cn 或 ua.ulearning.cn）
2. 页面右侧出现「小蟑螂」浮动按钮，点击打开面板
3. 顶部点击「题库导出」，再点击「开始导出课件题库」
4. 弹出章节选择界面，勾选需要导出的章节
5. 点击「导出所选章节」，等待进度完成
6. JSON 文件自动下载

### 导出训练题库

1. 打开优学院训练答题页面（lms.dgut.edu.cn）
2. 点击浮动按钮打开面板
3. 点击「开始导出训练题库」
4. 等待导出完成，JSON 文件自动下载

### 自动刷课

1. 打开课件学习页面，面板会直接进入「自动刷课」。
2. 设置倍速、页面停留时间及需要的播放选项；答题准确率和翻页重试次数可在「高级设置」调整。
3. 点击「开始自动刷课」。有课程目录时，脚本先预读专题和页数，再开始当前页面流程；预读失败会暂停并显示原因。
4. 运行中查看全课页数、当前页标题和运行日志。每 30 秒输出一次统计；已确认的页面变化才计入翻页进度。
5. 卡在某页时先暂停，可在「高级设置」使用手动定位。脚本仅按平台现有的完成标记寻找页面；没有可靠标记时会提示，不会猜测位置。
6. 需要停止时点击「暂停」。同一页包含多组练习时，脚本会逐组识别并处理；填空或简答题控件无法可靠填写时会停在当前页供手动检查。

> 请遵守学校课程和测验规定，仅在允许的学习练习场景使用自动化功能。不要在正在进行的考试中使用自动答题或绕过平台规则。

### 输出格式

```json
[
  {"题型":"选择题","题干":"题干内容","选项":["选项一","选项二"],"答案":"ABC","解析":""},
  {"题型":"判断题","题干":"题干内容","答案":"正确/错误","解析":""},
  {"题型":"填空题","题干":"题干内容和{答案}","解析":""},
  {"题型":"问答题","题干":"题干内容","答案":"答案内容","解析":""}
]
```

### 导入佛脚刷题

[佛脚](https://www.fojiao.app/) 是一款考前刷题工具，支持导入自定义题库，适合考前集中复习。

**导入步骤：**

1. 用本工具导出题库，得到 JSON 文件
2. 打开 [佛脚](https://www.fojiao.app/) 网站或 App
3. 进入「我的题库」→「导入题库」
4. 选择「JSON 格式导入」
5. 上传导出的 JSON 文件
6. 确认导入，即可开始刷题

**佛脚使用技巧：**

- **错题本** — 做错的题目自动归类，方便二刷
- **收藏夹** — 重点题目可以收藏，考前快速复习
- **随机模式** — 打乱题目顺序，避免记答案位置
- **背题模式** — 直接看答案，适合快速过一遍
- **模拟考试** — 按真实考试节奏限时作答

**建议复习流程：**

```
导出题库 → 导入佛脚 → 第一遍刷题（标记错题） → 二刷错题 → 考前快速过一遍
```

> 提示：建议在考试前 2-3 天导出题库，因为教师可能在考前更新题目。

## 常见问题

**Q: 导出的题目没有答案？**
A: 部分题目可能未设置答案。导出界面会显示未取回答案的数量，下载文件中不会为这些题目编造答案。

**Q: 自动刷课正确率怎么设置？**
A: 输入单个数字如 `98` 表示固定 98% 正确率；最低填 `95`、最高填 `98` 表示在 95%~98% 之间随机。

**Q: 导出的 JSON 文件怎么用？**
A: 可以导入佛脚、Anki 等刷题工具，或用 Excel/在线 JSON 工具查看。

**Q: 会不会被检测？**
A: 答题间隔已做随机化处理（±30% 波动），但请合理使用，不要过度依赖。

**Q: Token 过期了怎么办？**
A: 刷新页面重新登录即可，脚本会自动检测并提示。

### 运行中断排查

先看自动刷课面板的暂停原因，复制最近日志时删去账号、Cookie、令牌和课程编号。故障处理后可在当前页重新点击「开始」；已完成的题目不会被重复请求。

| 看到的状态 | 建议处理 |
|---|---|
| 登录失效、HTTP 401/403 | 在学校登录页重新登录，然后刷新学习页。 |
| 答案响应不是 JSON 或显示解析失败 | 确认安装的是 v4.1.3 或更新版本；新版会按莞工页面配置选择同源 API 代理。仍失败时复制脱敏日志。 |
| 多空或简答题提示“答案写入”失败 | 检查题目是否有比答案更多的输入框，或是否是脚本尚不支持的控件；当前页保留供手动处理，不会空提交。 |
| 提交按钮不可用 | 检查是否已作答、提交次数是否耗尽；已完成页会自动跳过，异常页会暂停。 |
| 翻页确认失败或长时间无进度 | 检查统计弹窗、网络加载和视频播放状态；处理后从当前页重启。脚本只把稳定变化计为成功翻页。 |
| 视频停滞或播放失败 | 先尝试页面原生播放按钮；脚本有限次重试后暂停并记录原因。 |

真实测试课程的只读扫描包含单选、多选、判断、综合、填空和简答题，但所有题目均已完成，因此多组、填空和简答题的自动填写/提交仍由隔离模拟页专项验证；不会为测试重做已完成题。真实课程纯翻页长跑已通过五专题门槛，视频播放场景仍需在含可播放视频的真实页面复验。
