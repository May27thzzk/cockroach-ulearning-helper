# v4.4 界面方向

参考用户提供的仪表盘图片，并保留用户选择的浅紫渐变与胶囊交互。侧栏以淡紫画布、暖白操作区和深紫主操作构成；暗色模式沿用相同的信息层级，以深梅紫画布和低亮度卡片承载内容。浏览器侧栏宽度有限，保留顶部三个功能入口，不复制宽屏的左侧菜单和图表。

## 视觉令牌

| 用途 | 颜色 |
| --- | --- |
| 浅紫画布 | `#f2edfc` |
| 暖白工作卡 | `#fffefd` |
| 主文字 | `#29243d` |
| 次要文字 | `#716a86` |
| 分隔线 | `#e4dcf1` |
| 紫色强调 | `#7350c4` |
| 深色画布 | `#231d35` |

中文使用系统界面字体，标题 18–20 px，正文 13 px，辅助文字至少 11 px。功能导航、底部主操作、常用开关和小型确认按钮采用胶囊形；开关用勾选标记表达状态，避免只靠颜色判断。设置分组放进白色卡片；每屏只保留一个最显眼的主操作。

## 窄侧栏结构

```text
┌ 品牌 / 当前页面 / 关于 / 关闭 ┐
│ 自动刷课  题库导出  读书计时 │
│                             │
│ 标题与简短说明               │
│ 白色设置卡                   │
│ 白色设置卡                   │
│ 高级设置（折叠）             │
│                             │
│ 固定的主要操作               │
└─────────────────────────────┘
```

设计审查重点：切换不重置正在运行的流程；刷课和计时不能同时操控页面；状态在切换后仍可看见；窄屏文字和输入框不能横向溢出。

## 操作反馈

主按钮与胶囊导航用约 140–160 ms 的颜色和阴影过渡；设置开关悬停时只增加轻微阴影，按下时短暂缩小到 98.5%，不改变布局位置。暗色主题对应调整悬停阴影；键盘焦点保留清晰轮廓，系统减少动态效果时缩短过渡。
